# 試作：手書き修正の反映チェック

確定打合せで図面に手書きした修正が、実施設計の最新図面に反映されたかを判定する試作（Python・OpenCV・PyMuPDF）。
画面への組み込み前に、実物の図面で精度を確かめるためのもの。**お客様の図面はリポジトリに入れない。**

```
pip install opencv-python-headless pymupdf numpy
python3 proto_reflect.py <手書きスキャンPDF> <打合せ前の版PDF> <打合せ後の版PDF> <出力フォルダ>
```

## しくみ
1. 全ページを画像にする（PyMuPDF。日本語フォントが描けないツールだと、文字がすべて「手書き」に見える）
2. スキャンの各ページに合う「打合せ前の版」のページを特徴点で探し、射影変換＋ECCで重ねる（iPhoneスキャンの台形ゆがみも直す）
3. 手書き＝スキャンにあって打合せ前の版にないもの（色ペン、または版の線から離れた黒）。印刷で太った直線は除く
4. 反映＝手書きの周り（約14mm）で、打合せ前→後の版の「形」か「同じ場所の文字（PDFの文字データ）」が変わったか
5. 指示外の変更＝前→後で変わったのに手書きがない場所

## 実物での結果（2026-11-05）
| 物件 | 結果 |
|---|---|
| 日野様邸（造作図・平面図） | 手書き7件中6件を検出、判定は6件とも正解。黒ペンの寸法1件を見落とし |
| 織部様邸（平面図・展開図・電気図） | 手書きのないページはすべて0件。平面図は書き込みが密で、指示が大きな塊になる → 場所だけでは判定が粗い |
| 井上様邸 | 打合せに使った版が残っておらず、最新版との比較のみ（参考） |

## 次にやること

- 丸付き番号（ページ番号・項目番号）は指示ではなく見出しとして扱う
- 打合せで使ったPDFを「打合せ用_日付.pdf」として残す運用にする（前の版がないと精度が落ちる）

# 架空ベンチ：資料間の照合と新旧比較の採点

MARKUP（書き込みの洗い出し）は実物4物件の正解表で測っているが、CHECK（新旧比較・資料間の照合）は
架空サンプル1組（食い違い4つ）でしか確かめていなかった。そこで、書き方のゆれを変えた**架空の物件**を
自動でたくさん作り、仕込んだ食い違い・変更をいくつ見つけたか、仕込んでいない指摘をいくつ出したかを数える。
すべて架空（お客様の資料は使わない）。作ったファイルはリポジトリに入れない。

```
python3 research/bench/make_bench.py <出力フォルダ> 24 1     # 物件数・乱数の種
node research/bench/score.mjs <出力フォルダ> [-v]           # -v で見落とし・余計な指摘の一覧
```

必要なもの：Python の reportlab・openpyxl、日本語フォント（IPAゴシックなど）、LibreOffice（見積の数式の値を入れるため。なくても動く）。

## 物件ごとに変えている書き方
- 寸法：`W1650xH1100` / 全角 / `1650×1100` / `W=1650` と `H=1100` の2行 / 寸法なし。すべての記号に書く・最初の1つだけ
- 記号：`AW1` / `AW-1` / 全角
- 建具表：Excel（ふつう・見出し2段・寸法が1つの欄）/ PDF の表（行が記号・列が記号）、数量が「2ヶ所」の文字
- 見積：品番の欄あり / 品名の中に品番、工事ごとの見出し行、1式・諸経費
- 図面：1階・2階に分かれる、照明を別の電気図に、照明の記号を器具ごとに書かない（凡例の数だけ）
- まぎらわしい文字：通り芯（X1・Y2）、図番（A-03）、工番、注記の記号（※AW1～AW5は…）、CH2400・GL+500・PS
- 新旧比較：図がまとまって動く、室名の書き換え、同じ寸法の数字がいくつも並ぶ、見積の行の追加・削除

## 結果（2026-11-28）

| | 作り直し前 | 作り直し後 |
|---|---|---|
| 24物件（種1）照合：見つけた | 64/77（83%） | **77/77（100%）** |
| 　　　　　　　照合：余計な指摘 | 542 | **0** |
| 　　　　　　　新旧比較 PDF | 96/114・余計42 | **113/114・余計1** |
| 40物件（種7。調整に使っていない）照合 | 104/129・余計857 | **129/129・余計0** |
| 　　　　　　　新旧比較 PDF | 159/185・余計58 | **185/185・余計0** |
| 新旧比較 Excel（両方） | 100%・余計0 | 100%・余計0 |

作り直し前の余計な指摘の多くは、通り芯（X1・Y2）と図番（A-03）を品番として「見積にない」と出していたもの、
注記の中の記号を図面の数に数えていたもの、平面図と電気図の数を比べていたもの。

残り1件（24物件）は、隣どうしの寸法の記入がつながって1つの文字になったもので、変更としては出ている（文字がつながったまま）。

**注意**：このベンチは「思いついた書き方のゆれ」しか測れない。実物の図面では別のゆれがあるはずなので、
実物で見落とし・余計な指摘が見つかったら、その書き方を `make_bench.py` に足してから直す。

# 金物着色（gran-kanamono）

構造図（金物図）の PDF を読み、**金物リストと壁の表（軸組みの種類と壁倍率）の記号ごとに色を決めて（設定）、図面全体の同じ記号に同じ色をつける**アプリ。
検査の前に手で色を塗っていた作業を置き換える。図面はブラウザの中だけで読み、外へは送らない。

## 使い方
1. **図面を選ぶ**：構造図の PDF を置く（または押して選ぶ）
2. **記号ごとの色分け（設定）**：「柱脚柱頭金物リスト」と「軸組みの種類と壁倍率」の表を自動で見つけて、記号ごとに色をつける
   - 同じ名前の金物（フックコーナーの ろ・は、シナコーナーの に・ほ・へ など）は同じ色。1行の色を変えると同じ名前の行もまとめて変わる
   - 色の丸を押すと色を変えられる。決めた色はこの端末に残り、次の図面でも同じ色になる
   - リストで斜線が引かれた行（使わない金物）は、はじめは「塗らない」
   - **基礎**：基礎伏図の「●凡例（符号・仕様）」の表と、基礎リスト（断面の一覧）も読む（下の「基礎図面」）
3. **図面全体に色をつける**：全ページから同じ記号を探して同じ色で塗る → 「色をつけたPDFを保存」
   - 確かめてほしいこと：斜線の金物・壁が図面にある（赤い輪）・リストにない記号がある

## 起動
```
npm install      # ライブラリと画面用ファイル（public/vendor）を用意
npm start        # http://127.0.0.1:3986/
npm test         # 単体テスト（架空のデータ）
node scripts/check.mjs <図面.pdf> [書き出し先.pdf]   # 画面なしで、見つけたリストと記号の数を確かめる
python3 scripts/build_artifact.py <出力先>           # スマホで開ける claude.ai Artifact 版
```

## 仕組み
| 処理 | どうやっているか | ファイル |
|---|---|---|
| 文字を読む | pdf.js の `getTextContent()`。字ごとに位置と大きさを取る | `public/js/pdfread.js` |
| 金物リストを見つける | 「金物リスト」の見出し → その下の「記号」の列 → 行ごとに記号・名称・引張。「●」「※」で表の終わり | `public/js/core.js` `findLegend` |
| 使わない金物（斜線） | リストの範囲の線を pdf.js の描画命令から取り出し、行をまたぐ斜めの線がある行 | `readSegments` / `findLegend` |
| 図面の記号を拾う | リストと同じ字のうち、**いちばん多い字の大きさ（±12%）**のものだけ。通り芯の丸文字や表の字は大きさが違うので除かれる | `findMarks` |
| 壁の表を読む | 「軸組みの種類と壁倍率」の見出しの下の長い横線で行を分け、各行の左端の図形を記号、「壁倍率」の見出しの真下の数字を壁倍率とする。斜線の行は使わない | `public/js/walls.js` `findWallLegend` |
| 壁の記号を探す | 点線（通り芯）の短い線を取り除いてから、図面の線を重なり合う図形ごとにまとめ、表の記号と形を比べる（24×24 のます目。回転・裏返しの8通り。縦横の比も比べる）。似ている度合い 0.9 以上で、2番目に似た記号と差があり、線の混み具合も近いものだけ。合わない図形は、端と端のつながりで部品に分け（4本以上の線が集まる点ではつながない＝記号どうしの接点。相手のいない端は 0.35pt 以内の切れ目とつなぐ＝弧に分けて描かれた丸）、内側に入る部品をまとめてから1つずつ比べる（丸の面材に筋かいの三角がくっついている場合など）。表と「凡例」欄は探さない。図面名に「伏図」があるページだけで探す（詳細図の溶接の三角などを拾わない） | `findWallMarks` `splitCluster` |
| 色をつけた PDF | pdf-lib で元の PDF に半透明の丸を「乗算」で重ねる（線と文字は元のまま） | `public/js/paint.js` |

実物での確認（物件 hi）：
- 金物：リスト10行・斜線4行・図面の記号103か所（ろ35・は28・へ16・に11・ほ8・と5）をすべて正しく拾い、通り芯の丸文字は塗らない
- 壁：表8行（斜線1行）を読み、柱伏図で43か所（片筋かい16・たすき掛6・面材15・面材入隅2・MIRAIE 4）、基礎伏図で37か所。取り違え0（新しく拾った記号は1つずつ目で確認）

実物での確認（物件 it）：金物89か所。壁は柱伏図36か所・基礎伏図35か所。丸の面材のすぐ横に筋かいの三角がある所も、別々に塗れる。斜線の「KRASOL」（塗りつぶしの三角）との取り違え0

## 基礎図面（基礎伏図・基礎リスト）
現場の手書き（検査前の塗り方）に合わせた色分け。`public/js/kiso.js`

| 塗るもの | 見つけ方 | はじめの色 |
|---|---|---|
| 外周の基礎（外まわりの立上り） | 地縄寸法図の外周判定（建物の仕上げ面を角だけの多角形にし、袖壁は別扱い）にならう。基礎伏図の実線のうち「平行な2本の線（壁）」と柱の四角などの短い線だけをます目に描き、外側から線にぶつかるまで塗りつぶして建物のかたまりを求める。幅 12pt 未満の細い出っ張り（文字の枠・袖壁・壁の外の記号）は削り、外の縁を角だけの多角形にする。外の縁から 3pt 内側を中心に、太さ 6pt の線を引く | 水色 |
| ホールダウン（15kN・20kN・Hi など） | 図面の「15kN」などの文字。凡例の使う行（斜線なし）と照らし合わせ、左上から番号を付け、凡例の行に数（×3）を書く。斜線の行の金物が図面にあれば赤い輪 | 赤 |
| 人通口 | 「W600」「W740」などの文字（縦書きの1字ずつの字もつないで読む） | だいだい |
| 開口補強 b・c | 「開口補強b」の文字 | 桃 |
| 梁符号 | 「FG1」「FG5」などの文字。FG1＝水色、FG2＝緑、FG4＝だいだい、FG5＝桃、FG3（特記なし）＝塗らない | 符号ごと |
| スラブ | 注記「スラブはS200とする」と違う符号（S150・S100 など） | 桃 |
| 独立基礎・独立柱 | 「独立柱」「独立基礎」の文字 | だいだい |
| 基礎リスト | 断面の見出し（FG1・S200 など）に梁符号と同じ色。×が描かれた断面は使わない。鉄筋の本数（2-D13 など）に赤い輪 | — |

- 基礎伏図では、筋かい・面材など壁の記号は塗らない（柱伏図だけ塗る）
- 実物での確認（物件 hi）：凡例18行（ホールダウン15kN用が使う行）、図面の15kN 3か所に番号、人通口・開口補強b 2か所・梁符号・スラブS100・独立柱、基礎リストの×の断面（S150）
- 外周：物件 hi は角10か所。地縄寸法図（同じ物件）の建物の角と同じ位置で、袖壁の部分は外周に入らない
- 実物での確認（物件 it）：ホールダウンの行はすべて斜線、人通口、梁符号 FG1・FG1A・FG5、スラブS150、基礎リストの×の断面（FG2・FG2A・FG4・S100）

## できないこと（今後）
- 文字が画像になっている PDF（スキャン）：文字を読めないので、リストが見つからないと表示する
- 壁の記号で、線が欠けている・壁の線などとくっついているものは見つけられないことがある（点線が上を通るものは見つける）
- 基礎：外周以外の梁（FG4・FG5 など）は符号の文字に色をつけるだけで、梁の線に沿った帯はまだ。配置図（境界からの距離・KBM）はまだ
- リストの表の形が大きく違う図面（別のプレカット会社など）：実物で確かめて合わせる

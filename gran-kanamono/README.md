# 金物着色（gran-kanamono）

構造図（金物図）の PDF を読み、**金物リストの記号ごとに色を決めて（設定）、図面全体の同じ記号に同じ色をつける**アプリ。
検査の前に手で色を塗っていた作業を置き換える。図面はブラウザの中だけで読み、外へは送らない。

## 使い方
1. **図面を選ぶ**：構造図の PDF を置く（または押して選ぶ）
2. **金物リストの色分け（設定）**：「柱脚柱頭金物リスト」を自動で見つけて、記号ごとに色をつける
   - 色の丸を押すと色を変えられる。決めた色はこの端末に残り、次の図面でも同じ色になる
   - リストで斜線が引かれた行（使わない金物）は、はじめは「塗らない」
3. **図面全体に色をつける**：全ページから同じ記号を探して同じ色で塗る → 「色をつけたPDFを保存」
   - 確かめてほしいこと：斜線の金物が図面にある（赤い輪）・リストにない記号がある

## 起動
```
npm install      # ライブラリと画面用ファイル（public/vendor）を用意
npm start        # http://127.0.0.1:3986/
npm test         # 単体テスト（架空のデータ）
node scripts/check.mjs <図面.pdf> [書き出し先.pdf]   # 画面なしで、見つけたリストと記号の数を確かめる
python3 scripts/build_artifact.py <出力先>           # スマホで開ける claude.ai Artifact 版
```

## 仕組み
| 処理 | どうやっているか | ファイル |
|---|---|---|
| 文字を読む | pdf.js の `getTextContent()`。字ごとに位置と大きさを取る | `public/js/pdfread.js` |
| 金物リストを見つける | 「金物リスト」の見出し → その下の「記号」の列 → 行ごとに記号・名称・引張。「●」「※」で表の終わり | `public/js/core.js` `findLegend` |
| 使わない金物（斜線） | リストの範囲の線を pdf.js の描画命令から取り出し、行をまたぐ斜めの線がある行 | `readSegments` / `findLegend` |
| 図面の記号を拾う | リストと同じ字のうち、**いちばん多い字の大きさ（±12%）**のものだけ。通り芯の丸文字や表の字は大きさが違うので除かれる | `findMarks` |
| 色をつけた PDF | pdf-lib で元の PDF に半透明の丸を「乗算」で重ねる（線と文字は元のまま） | `public/js/paint.js` |

実物（金物図1物件）での確認：リスト10行・斜線4行・図面の記号103か所（ろ35・は28・へ16・に11・ほ8・と5）をすべて正しく拾い、通り芯の丸文字は塗らない。

## できないこと（今後）
- 文字が画像になっている PDF（スキャン）：文字を読めないので、リストが見つからないと表示する
- 筋かい・耐力面材の記号（三角・▼など、線で描かれた記号）の色分け
- リストの表の形が大きく違う図面（別のプレカット会社など）：実物で確かめて合わせる

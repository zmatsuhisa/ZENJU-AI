# gran-sun3d（日照3D）

敷地のまわり半径約300mの街並みを、国土地理院のベクトルタイルから3Dで組み立てて、
日付・時刻ごとの影と、敷地の直射日照時間を確かめるブラウザのツール。
計算はすべてブラウザの中（three.js と `public/js/sun.js`）で行い、外へは何も送らない。

## できること
- 日付・時刻を動かして、街の影と太陽の位置を見る（冬至・春分・夏至・秋分はボタン1つ）
- 敷地の日照時間マップ（1m間隔）
- **まわりの建物の高さを直す**：3Dで建物を押す（または「敷地に影を落とす建物」の「選ぶ」）→ 階数を ＋／− 。
  直した高さはその端末に残る（`localStorage` の `gos-sun-h-<記号>`）
- **敷地に影を落とす建物**：選んだ日に、敷地へ長く影を落としている建物の上位5棟と、その時間
- **計画の建物を置いて比べる**：平屋／2階建ての箱を置いて、南の庭（平均）と1階LDKの窓（南の面のまん中・床から1.2m）の
  日照時間を、冬至・春分・夏至で並べて比べる。大きさ・位置はスライダー、パソコンでは3Dの箱を引っぱって動かせる
- 敷地が2つ以上あれば、右上で切り替え
- **建物の大きさ**：配置図と3Dの「計画の建物」に、1階・2階・延べ床面積（㎡・坪・帖）、建ぺい率・容積率、間口×奥行、軒とてっぺんの高さ、
  敷地の残り、外周・外壁・屋根の面積（概算）、境界までのいちばん短い距離（北・東・南・西）、隣の家までの距離と高さ（南は冬至の正午の影の長さ）を出す（`public/js/size.js`）
- **配置図（`plan.html`）で建物の外周を手で描く**：線を描くたびにブレを直線に直し、角度（直角だけ／45°も／そろえない）と
  マス目（910／455／1000／寄せない）にそろえ、描き始めの点に戻ると閉じる。角・辺・建物を引っぱって直せる。階数（平屋／2階）、
  LDKの窓の位置も決められる。建築面積・建ぺい率・辺の長さ（mm）・境界から50cmの線を出す。描いた形は端末に残り（`gos-sun-draw-<記号>`）、
  3Dの「計画の建物」の「配置図の形」で影と日照の計算に入る
- **寸法で合わせる（配置図の「寸法」）**：建物の辺→敷地の境界線を押すと、辺を境界と平行にして「境界から何mm」を決められる。
  建物の角→敷地の角を押すと、敷地の角から2本の境界線それぞれに沿って何mmの所か（追い寸法。例：北の境界に沿って1,000・西の境界に沿って900）を決められる。
  境界線の上のその点から直角に下ろした所が建物の角になる（角どうしのまっすぐの距離も出す）。
  決めた寸法は青い寸法線で図に残り、**あとで直しても守られる**：建物ごと動かすと決まっていない向きにだけ動き、
  決めた辺は境界からの距離を保ったまま線の上を滑り、決めた角は動かない。角を足す・消すと寸法の番号を付け直す。
  ほかの寸法があるときに辺の寸法を足すと、建物は回さず辺のまん中で測る。寸法の道具で同じ所を押すと「外す」
- **配置図の操作の手助け**：描いている途中から直した形を点線で見せる。1つ戻す／やり直す（Ctrl+Z／Ctrl+Y）。
  「直す」で角を2回押すと角を消し、辺を2回押すと角を足す。角・辺は境界線と50cmの線の近く（画面で10画素）で吸い付く。
  パソコンでは矢印キーで選んだ建物をマス目1つ分動かし、Delete で消す
- **2つのページの連動**：日付・時刻（`gos-sun-time`）を共有し、片方で変えるともう片方も合わせる。配置図の ☀ で同じ時刻の影を出す。
  配置図で描き直して3Dに戻ると、自動で「配置図の形」にする。3Dで直した隣家の高さは配置図の影と計算にも使う
- スマホでは、拡大しなくても1本の指で回す・2本の指で寄る／ずらす。ページのスクロールは3Dの外側（上の見出しや下のドック）で

## 動かし方
```
cd gran-sun3d
SITES=<敷地データのフォルダ> npm start   # → http://127.0.0.1:3986/?site=<記号>
npm test                                 # 太陽の位置・影の判定・計画の建物・線の直し方（22件）
```
敷地データ（`sites/index.json` と `sites/<記号>.json`）はお客様の敷地の位置と形なので、**リポジトリに入れない**。
リポジトリの外のフォルダに置いて `SITES` で渡す（`public/sites/` は .gitignore 済み）。

`sites/index.json` の形：`[{"key": "ha", "name": "画面に出す名前"}, ...]`

## 敷地データの作り方
1. 地理院のタイルから建物・道路・水路を取り出す（タイルは `--download` で 3×3 枚取ってくる）
   ```
   python3 tools/extract.py --lat <緯度> --lon <経度> --tiles <タイルのフォルダ> --out <area.json> --download
   ```
   （`pip install mapbox-vector-tile` が必要）
2. 敷地の設定ファイル（リポジトリの外）を書く。形は `tools/build_data.py` の先頭に説明あり。
   敷地は角の座標 `lot`、または長方形 `lotRect`（間口・奥行・向き・中心）で書ける
3. 画面用のデータを作る
   ```
   python3 tools/build_data.py --area <area.json> --site <敷地の設定.json> --out <SITESのフォルダ>/<記号>.json
   ```
4. `sites/index.json` に足す

### 地面の高さと遠くの山を入れる
```
python3 tools/terrain.py --lat <緯度> --lon <経度> --cache <タイルのフォルダ> --out <terrain.json>
python3 tools/build_data.py ... --terrain <terrain.json>            # 作るときに入れる
python3 tools/terrain.py --apply <terrain.json> --site-json <SITESのフォルダ>/<記号>.json   # できている敷地データに足す
```
- 地面：国土地理院の数値標高モデル 5m メッシュ（航空レーザー測量）を、敷地を中心に 700m 四方・5m 間隔で読む。
  敷地の中央を 0 とした高さ（cm）で入れ、建物の足元の高さ（`y`）も足す
- 遠くの山：10m メッシュで半径 30km を見て、方角1度ごとに山が見える角度（`hor`）を出す（地球の丸みと大気の屈折を引く）。
  太陽がこれより低い時間は日照に数えず、3Dでは光を消して「山の陰」と出す
- 3D：地面・道路・建物・木・敷地・計画の建物を地面の高さに置く。配置図：等高線と敷地の角・中央の標高。
  盛土（配置図の設定・`gos-sun-fill-<記号>`）を入れると、計画の建物・南の庭・LDKの窓がその分高くなる

### 建物を PLATEAU（実測の高さ）にする
PLATEAU（国交省の3D都市モデル）の建物がある市町村では、建物の形と高さを航空測量の実測にできる。
```
python3 tools/plateau.py --lat <緯度> --lon <経度> --cache <CityGMLのフォルダ> --out <plateau.json> --download
python3 tools/build_data.py --area <area.json> --site <敷地の設定.json> --plateau <plateau.json> --out <SITESのフォルダ>/<記号>.json
```
- 敷地まわりの3次メッシュ（約1km四方）の建築物 CityGML を、PLATEAU のデータカタログ API で探して取ってくる（無料・登録不要）
- 実測の高さ（measuredHeight）・屋根の外周（lod0RoofEdge）・地上階数・構造を使う。木造（12m以下）は実測の高さを棟とみなし、4.5寸の切妻で軒の高さを逆算する
- 画面では「実測」と出る。直した高さは地理院版と別に残す（建物の番号が変わるため）
- 出典の表示：3D都市モデル（Project PLATEAU）国土交通省

## 決まりごと
- 座標は 原点＝ピン位置、x=東、z=南（three.js では -z が北）、単位 m
- 建物の高さは地理院データにないので推定（木造2階6m前後＋切妻・22%は平屋3.3m、堅ろう9〜16m、大型6.5〜9m、無壁舎3m）
- 日照は建物の平面形＋高さで判定（10分刻み）。木と車は計算に入れない
- 階数⇔高さ：木造 1階3.3m・2階6.2m・3階9.1m（＋切妻）、鉄骨・RC 3.5m×階＋0.5m
- 計画の建物：平屋の軒3.3m・2階の軒6.2m に 4.5寸の切妻。棟は東西。向きは敷地のいちばん長い辺に合わせる
- 配置図で描いた建物：屋根の形が分からないので、軒の上に平均1.0mを足した高さで計算する。南の庭は「真北を見ると計画の建物がある敷地」
- 見た目は `public/gran-os-base.css`（グランOS v2.1。値は変えない）、このアプリだけの部品は `public/app.css`

## ファイル
```
public/index.html   3Dの画面
public/plan.html    配置図の画面（建物の外周を描く）
public/app.css      このアプリだけの見た目
public/js/sun.js    太陽の位置・影の判定・日照時間・計画の建物の計算（画面とテストで共用）
public/js/app.js    3Dの組み立てと操作（three.js r128）
public/js/draw.js   手で描いた線を直線・角・マス目にそろえる計算（画面とテストで共用）
public/js/plan.js   配置図の描画と操作
public/js/size.js   建物の大きさ（床面積・外形・境界と隣家までの距離）
tools/extract.py    地理院タイル → area.json
tools/build_data.py area.json＋敷地の設定（＋plateau.json）→ sites/<記号>.json
tools/terrain.py    国土地理院の標高タイル → terrain.json（地面の高さと遠くの山）
tools/plateau.py    PLATEAU の建築物 CityGML → plateau.json（建物の形と実測の高さ）
server.js           パソコンで開くための小さなサーバー
test/*.test.js      計算のテスト（22件）
```

## claude.ai の Artifact（スマホで開ける版）にするとき
`public/` の中身と、`SITES` のフォルダの `sites/*.json` を、同じ並び（`sites/…`）で1つの Artifact に載せる。
